# Executable controlled sketch protocol

October 15, 2026. Prospective specification for new data; local protocol, not an external preregistration. Supersedes proposed implementation details in SEMANTIC_PROTOCOL.md for the experiment executed here. The earlier 3D asset experiment remains a later external-validity test.

## Scope and data

Question: can a universal text-derived red→blue direction improve a paired intervention margin on held-out drawing categories after supervised endpoint mapping? These are synthetic stroke recolorings of real human sketches, not photographed red/blue objects and not evidence of natural-image compositionality.

Google Quick, Draw!, CC BY 4.0: https://github.com/googlecreativelab/quickdraw-dataset . Derivatives recolor and recenter simplified drawing strokes. Download a prefix of 400 game-recognized, nonempty drawings per category, then select 40 without replacement using the saved seed (12 for pilot). Prefix selection is not a probability sample of the entire corpus. Drawing key IDs are unique; author IDs are unavailable, so author independence is not guaranteed. Retain only key ID, drawing, category and recognized flag; do not retain country/time metadata.

Exact pilot and main category partitions, RGB values, template strings, dimensions and seeds are in configs/semantic_quickdraw.json. Pilot categories are retired and disjoint from all 24 main categories. Each drawing produces one red and one blue image; recoloring preserves the mask, antialiasing and gray background exactly. Background is a deterministic two-level balanced nuisance within category. RGB colors are channel-swapped and are not perceptually luminance matched: this is an RGB stroke intervention, not an isolated hue experiment. Every selected drawing is retained without score-based exclusions. Save raw-subset, mask and image hashes; reject duplicate key IDs or duplicate masks. Make contact sheets for visual QA. Game recognition is not a human-verified semantic label, and category-label noise remains a limitation.

## Representation and fitting

Pinned cached BLOOMZ1.7B/DINOv2 base weights and extraction code conventions, layers 19/10. FP32 MPS extraction, CPU scoring. Language layer counts the embedding output as index 0; vision block index is zero-based. First half of training drawings fit the map, second half supply an image-direction reference. All four matched templates occur within each map-training category/color. Unique prompts are embedded once.

Train-only original clipping rule and L2 normalization; centered PCA **32**, without whitening, fitted separately per modality on map-training rows; normalize projected endpoints. The change from proposed PCA128 avoids a rank-deficient language representation from repeated templated captions: the main map has only 64 distinct captions. Pilot PCA8 is a separate debugging setting. No dimension/layer/alpha choice uses main test outcomes. Alpha=1. Choose direction scale on validation only; ascending-scale tie break. Four templates are averaged within each category, then categories are averaged equally. No main test words enter the universal direction or map fitting. A direct-target-text reference deliberately uses test-category words and is labeled stronger-information recognition.

## Controls and scoring

Evaluate no shift, mapped text relation, reverse of mapped relation at the same scale, 100 fixed-seed equal-norm isotropic image-coordinate random directions at the text scale, 100 training category sign-randomized text relations mapped and norm matched in image coordinates, image relation estimated on the separate training half (own validation scale), and orthogonal Procrustes text transfer (own validation scale). Add an affine direct-target-text endpoint prediction as a recognition reference.

A proposed category-pair shuffle is invalid for an averaged relation: mean(x_blue[perm]−x_red)=mean(x_blue−x_red). Demonstrate this identity in tests. Sign randomization changes source/target orientation within categories, without pretending that shuffled marginals remove the color offset. Its small training category count permits some nearly identical controls; keep all draws and report the control distribution. These are diagnostics, not permutation p-values for an adaptive training pipeline.

Primary per-drawing score is cosine(translated red, matched blue) − cosine(translated red, original red). Report paired gain over no shift. Because random translation can improve this margin by moving away from the original query, require comparison with both equal-norm random shifts and reverse shifts. Three primary paired contrasts: text minus no-shift; text minus mean random shift; text minus reverse. Bonferroni intervals at 1−.05/3=98.3333% (two-sided percentile bootstrap) plus ordinary95% intervals. Main test uses 12 held-out categories with40 drawings each. Resample categories then drawings within sampled category,20,000 draws; report category-only and leave-one-category-out sensitivity. Bootstrap draws/seeds and category-level data are saved. Labels/source dependence and nonrandom category selection restrict population inference.

Retrieval: for each query index i, omit red drawing i and blue drawing (i+1)%N in every candidate category. This excludes the query, retains its blue counterfactual and gives N−1 candidates of each color in every category. Save exact bank exclusion rule and row order. Score same-category and all-category banks, with target-color top1, category top1, joint target-color/category top1 and matched-blue rank. No-shift retrieval may already retrieve the near-identical blue drawing; report that ceiling explicitly rather than crediting it to translation.

Object-preservation guardrail: one-sided95% lower bootstrap bound for category-top1(text)−category-top1(no shift) must exceed −.05. Claim a controlled RGB relation only when all three primary adjusted intervals are positive and this guardrail passes. Meaningful-effect reference is .02 absolute margin gain: a null result is not equivalence unless its upper bound is below .02. Single relation/model pair results are a proof of concept; reverse relation, second relation/family, and natural data are still required for broad claims.

## Pilot completion and main freeze

All four pilot categories were evaluated in four rotations (two fitting, one validation, one test) using the fixed PCA8 pilot setting; these fits overlap. `pilot_planning.py` reports a rough normal-approximation 80%-power MDE at12 categories of .0432, .0383 and .0700 for the three contrasts, based on only four pilot category effects. This does not establish sensitivity to a .02 effect. The24-category main budget is retained to test pilot-sized effects; smaller or uncertain effects will require more test categories. No main features or scores were inspected in making this decision.

Pilot “alarm clock” is semantically close to proposed main “clock”, so the main category was changed to “scissors” before main acquisition/feature extraction. Pilot labels, fitted representations and stored results are preserved. All main categories remain disjoint from pilot concepts at this level. CPU analysis uses float64 for SVD, regression and scoring on float32 extracted features. The main lock saves the protocol/configuration, code and tests before main extraction; the lock is a local audit trail, not external preregistration. No inference over model families or all possible object categories is justified.
